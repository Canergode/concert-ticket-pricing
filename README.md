## What I Learned

- How to nest an `if / else if` inside another `if / else if` to evaluate a second condition only when the first one applies
- How to use a `1`/`0` input value to represent a yes/no answer (student status)
- How to apply a percentage discount to a variable that was initialized with a default value (`ticket_price = 500`)
- How different branches of the same program can produce different output formats (free message vs. price message)
